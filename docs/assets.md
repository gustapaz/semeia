# Assets e referências

Tabuleiro vertical, cavidades, grãos de madeira, sementes marfim, tipografia e composição foram criados em CSS/DOM neste projeto. Texturas são gradientes procedurais, sem imagem de banco. Fontes do sistema (Arial/Georgia/monospace), sem downloads. Áudio é sintetizado por Web Audio com notas curtas após ativação opcional; sem músicas/samples de terceiros.

Mithril.js usa MIT. O build copia sua licença integral de `node_modules/mithril` para `public/third-party.txt`, com versão instalada, e a inclui no site. Nenhum histórico ou código de um jogo pronto foi importado. Regras do tipo Kalah são a referência mecânica; apresentação e código são próprios. Não copiamos identidade visual ou assets de um produto comercial.

Referências técnicas: [Mithril.js](https://mithril.js.org/) e [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages). Todas as informações de partida são sintéticas/locais, sem dados pessoais de demonstração.
